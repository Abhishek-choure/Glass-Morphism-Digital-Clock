
# 🕒 Glassmorphism Digital Clock

A modern and responsive digital clock built using HTML, CSS, and JavaScript. It features a glassmorphism user interface, a real-time digital clock, an animated analog clock, and an interactive calendar.

## ✨ Features

- **Live Digital Clock** – Displays the current time and updates every second.
- **Analog Clock** – Animated hour, minute, and second hands.
- **12-Hour / 24-Hour Format** – Switch between time formats.
- **Interactive Calendar** – Navigate between months and select dates.
- **Today Button** – Quickly return to the current date.
- **Show / Hide Seconds** – Customize the digital clock display.
- **Light / Dark Mode** – Switch between different visual themes.
- **Glassmorphism UI** – Frosted-glass effects with a modern design.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- CSS Flexbox and Grid
- CSS Animations and Backdrop Filter
- JavaScript Date Object and DOM Manipulation


2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enjoy the live clock and interactive calendar.

## 💻 How It Works

- JavaScript retrieves the current date and time using the built-in `Date` object.
- The digital clock refreshes every second.
- CSS transforms rotate the analog clock hands.
- JavaScript handles calendar navigation and date selection.
- CSS creates the glassmorphism appearance and responsive layout.

## 🎯 Project Objective

The objective of this project is to demonstrate front-end development skills through a real-time clock application with an interactive calendar and a modern, responsive user interface.
